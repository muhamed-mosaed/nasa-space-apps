# NASA Space Apps Challenge 2024
## Project: Earth System Trend Detective

### 📌 About the Project
Our team is building an interactive tool to analyze NASA Earth observation data. The tool detects significant trends (using the Mann-Kendall test) in climate variables (e.g., Temperature, Precipitation) over specific regions, providing visual evidence of climate change.

### 🛠️ Tech Stack
* **Language:** Python 3.11
* **Data Retrieval:** `earthaccess` (NASA API)
* **Data Processing:** `xarray`, `pandas`, `numpy`
* **Statistical Analysis:** `pymannkendall`, `scipy`
* **Visualization:** `matplotlib`, `folium`, `plotly`

### 🚀 How to Setup (For Team Members)
1. Install [Miniconda](https://docs.anaconda.com/miniconda/).
2. Clone this repository:
   `git clone https://github.com/muhamed-mosaed/nasa-space-apps.git`
3. Create the environment:
   `conda env create -f environment.yml`
4. Activate the environment:
   `conda activate spaceapps`
